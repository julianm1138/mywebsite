GuitarMap: A web-based application bult with React, TypeScript, Tailwind, and Supabase, that visually maps musical notes onto a realistic virtual guitar fretboard to enhance instruction and practice for students. Designed for music educators and guitarists, by a music educator and guitarist. GuitarMap provides a paperless and convenient alternative to tab books by allowing real-time display of note locations across all positions.

Client Website: Fully responsive website for a small business client in the pet apparel industry. Built from scratch using HTML, CSS, and JavaScript to match brand identity and drive customer engagement.

MedTrac: This a fullstack web app made using React, Node, Express, and MongoDB that provides patients a convenient way to keep track of their medication schedule.

Space Daily: Responsive web app built using HTML, CSS, and JavaScript that fetches NASA’s Astronomy Picture of the Day via public API. Renders high-res images and dynamic educational content daily. Designed with modular JS logic for scalable API handling and clean UI presentation.

Pokémon Party: Dynamic Pokémon party builder using Vue, TypeScript, Tailwind, and PokéAPI. Implements global state via Pinia for real-time updates across components, including data flow, color theming, and party logic. Mimics RPG-style inventory systems with scalable, modular architecture. Designed for future expansion with backend integration and user auth.
